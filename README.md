
# Планирование

### Описание проекта

Я бы хотел реализовать Telegram-бота для помощи в игре в покер. Две его основные функции будут 1) помощь непосредственно во время игры, то есть игрок может сообщать свои карты, а потом еще добавлять информацию о открывающихся картах и получать информацию о вероятности выиграть, а так же вероятность различных комбинаций по отдельности и 2) обучение, но тут будет только сами правила текстом и список комбинаций.

### Архитектура
class Card - это просто одна игральная карта

class HandValues - это енум-класс, отвечающий за покерные комбинации карт

class Combination - этот класс отвечает за то, что находится на руках у конкретного игрока и позволяет находить оптимальную комбинацию из возможных

class OneUser - самый восокоуровневый из покерных классов, позволяет добавлять карты и находить вероятность победы

class Bot - тут и так все понятно
