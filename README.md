
# Планирование

### Описание проекта

Я бы хотел реализовать Telegram-бота для помощи в игре в покер. Две его основные функции будут 1) помощь непосредственно во время игры, то есть игрок может сообщать свои карты, а потом еще добавлять информацию о открывающихся картах и получать информацию о вероятности выиграть, а так же вероятность различных комбинаций по отдельности и 2) обучение, но тут будет только сами правила текстом и список комбинаций.

### Архитектура
class Interface - Управляет всем

class Teleclass - Отвечает за взаимодействие с телеграмом

class Game - Отвечает за события одной игры

class Probability - Полностью реализует работу с вероятностями

class Educ - Отвечает за второй пункт(который про обучение) но возможно его вообще лучше не делать
